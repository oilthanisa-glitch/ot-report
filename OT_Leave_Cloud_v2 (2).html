รายงานขอเอกสาร · เวลาการทำงาน
⚙️ ถ้ากดแล้วไม่มีข้อมูล — คลิกดูวิธีแก้
ต้อง Publish to web ไฟล์ทั้งสองใน Google Sheets ก่อน:
1. เปิดไฟล์ใน Google Sheets
2. คลิก File → Share → Publish to web
3. เลือก Entire Document และ format เป็น Comma-separated values (.csv)
4. กด Publish → OK
5. ทำซ้ำกับอีกไฟล์ แล้วกดปุ่มคำนวณใหม่
กดปุ่มเพื่อดึงข้อมูลล่าสุดจาก Google Sheets
